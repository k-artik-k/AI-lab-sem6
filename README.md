# AI Lab – Semester 6

This repository contains the programs and experiments completed for the **Artificial Intelligence Laboratory (Semester 6)**.

The experiments focus on fundamental AI concepts such as search algorithms, reasoning, logic programming, and problem solving using Python and Prolog.

---

## Experiments

### Lab 1 – Python Libraries and Searching Algorithms

Introduction to Python libraries used in AI and basic search algorithms.

### Lab 2 – Vacuum Cleaner Problem

Implementation of a simple intelligent agent solving the vacuum cleaner environment problem.

### Lab 3 – Monkey and Banana Problem

A classical AI planning problem demonstrating goal-based problem solving.

### Lab 4 – Water Jug Problem (Prolog)

Solution to the water jug problem implemented using Prolog.

### Lab 5 – Eight Tiles, BFS, and LCS

Implementation of search techniques such as Breadth First Search and the Eight Puzzle problem along with Longest Common Subsequence.

### Lab 6 – Tic-Tac-Toe, Hangman, and Wordle

Game implementations demonstrating decision making and logical problem solving.

### Lab 7 – Inferential Logic

Programs related to logical inference and reasoning systems.

### Lab 8 – Propositional Logic

Implementation of propositional logic concepts using Python libraries.
